# Player Help - Echoes of Elarion

This folder holds the **player-facing help set** for *Echoes of Elarion* (Chapter One of
*Defenders of the Realm*). It is written for real players in plain, warm language - not for
engineers. It is the reference a player reaches for when they ask "how do I...?"

## Contents

| File | What it is |
|---|---|
| **[HELP_GUIDE.md](HELP_GUIDE.md)** | The full player guide - founding your realm, your hero, building & upgrading, defending, dungeons, Echoes, currencies, the store & wallet, and a preview of raiding. |
| **[FAQ.md](FAQ.md)** | Short answers to the most common player questions. |

## About this help set

- **Player-facing.** Copy is warm, concise, and free of internal jargon and code names. Canon
  terms are used exactly as players see them: **Elarion**, the **Heart of Elarion**, **Echoes**,
  and the **Builders / Training / Research** work channels.
- **Accurate, not aspirational.** Everything is grounded in how the game actually plays today.
  Pillars still in development (currently **raiding** and **troops/training content**) are
  clearly marked **(Coming Soon)** and described as design previews, never promised as live.
- **Kept in sync (project rule Section 15).** When a system ships, changes, or a "Coming Soon"
  feature goes live, update the matching section here **in the same change** so the help set
  never drifts behind the game.

## Maintainers

If you add or change a player-facing system, check whether the guide or FAQ needs a matching
edit. Ground every update in the real systems (and the live canon in
`CANON_GROUND_TRUTH_<date>.md` / `KEY_FACTS.md`), never in assumptions.
