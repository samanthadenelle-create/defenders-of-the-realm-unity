## Verdict in one line
The **recently-polished panels are excellent** (Echo Unlock card, Pause, Game Guide, Jukebox, Alchemy, Jeweler
content). The problems are concentrated in the **older, un-reworked panels** and fall into a small number of
repeatable lanes — most of them fixable with one shared change (opaque body + full-screen dim scrim).

**The bar to match:** the Echo Unlock card — opaque black body, big gold heading, body copy at a genuinely
readable size, three clearly-separated buttons, zero overlap. Every panel below should meet that bar.

## P0 — blocks readability / usability on mobile

### P0-1 · Semi-transparent panels — the world bleeds through the text
The panel body is not opaque, so the 3D scene (world tree, hero, castle walls) and leftover HUD/tutorial chrome
show straight through the copy. On a phone this makes the text nearly unreadable.
- **Worst:** **Report a Bug** — almost fully transparent; only the input field is opaque.
- **Also:** **Building Upgrade (Arcane Tower)**, **Hero Loadout (Hot-Swap Skills)**.
- **Root fix (shared):** every modal gets (a) an **opaque body background** and (b) a **full-screen dim scrim**
  behind it. This single change also fixes the dead-margin bleed in P2-8 and the tutorial-banner bleed in P2-12.

### P0-2 · Skill tree action bar floats over the talent grid
On **Hero Skills** ("Garran (Knight) Skills"), the **Cancel / CONFIRM / Respec 300c** bar renders in the
*middle* of the tree, overlapping the bottom row of talent nodes; stray "1 + 3 +" / "2 + 4 +" cost markers sit
orphaned beside it. The action bar must dock to the **bottom** of the panel, below a scrollable tree area.

### P0-3 · Party Shop header controls collide
On **Party Shop**, the hero portrait overlaps the "Grom" name, which overlaps "Grom Knight (Lv 1)", which
overlaps the **BUY/SELL** toggle, which overlaps the **All / Armor / Weapons** category row and the second
**All / Heavy / 1h / Shield / 2h** row. The entire header cluster is crushed and unreadable. Rebuild the header
as clean, separated rows with breathing room.

## P1 — content is lost (truncation / clipping / leaks)

### P1-4 · Text truncated mid-word
- **Realm Store:** reward lines clipped; **"Buy 240 S..."** button label cut; the 5th pack ("Founder's Vow")
  is sliced by the scroll edge.
- **Building Upgrade:** tier descriptions clip mid-word ("...Struc", "...+", "...Ar"); right-panel bullets clip
  ("Opens arcane research. Structure", "Opens Mana Flow (Tower damage"); buttons read **"Unlock 'Aw"**,
  **"Unlock 'Ma"**, **"Unlock 'Arc"**.
- **Fix:** reflow/wrap copy, widen buttons to fit their labels, never hard-clip.

### P1-5 · Primary CTA clipped by / hidden behind the Close button
- **Jeweler's Bench:** the craft CTA reads **"...EMS – need the base piece"** — left edge cut and the button
  sits partially behind the centered Close button.
- **Help:** the Close button overlaps the last menu row, leaving two orphaned empty button-halves flanking it.
- **Fix:** give Close its own dedicated row; the screen's primary CTA must sit fully clear of it.

### P1-6 · Debug string leaking into the Store header
**Realm Store** shows a raw base58 wallet address — `Rewards Distributor - 2JRmEmnqUbhTiHX3u5be5kHY…` — as tiny
header text. Remove it from the shipped UI or gate it behind the dev flag.

## P2 — polish / mobile-fit

- **P2-7 · Low-contrast secondary text.** Descriptions and reward/price lines are small grey italic on black
  (**Store**, **Cosmetic Shop**). Bump size + contrast for phone legibility.
- **P2-8 · Narrow modals, big dead side-margins.** **Store / Cosmetic / Jukebox / Party** use only ~half the
  screen width; the rest is empty (and shows the world through it). Widen the content column for mobile landscape
  (and see P0-1's scrim).
- **P2-9 · Tiny / garbled icons.** Inventory rarity badges (the "U"/"C" letters) and the resource chips
  (gold / crystal / third stat) are illegible; grid item icons are tiny inside oversized cells.
- **P2-10 · Settings difficulty buttons.** "Normal" and "Hard" render in dark low-contrast text; the
  selected-state is unclear. Match the readable weight of the audio rows.
- **P2-11 · Desktop control copy on a touch build.** **Game Guide** → Basic Mechanics says *"Walk with WASD,
  the arrow keys, a…"* — keyboard language on an APK. Rewrite control copy touch-first.
- **P2-12 · Tutorial banner bleeds over panels.** The "Place the Echo Hollow… / Skip Tutorial" tutorial overlay
  renders over/through panels opened during the tutorial (z-order + no scrim). Largely resolved by P0-1's scrim;
  verify z-order after.
- **P2-13 · Inventory tab label clipped.** The selected "Weapons" tab reads "Weapon" — the pennant shape eats the
  last letter. Minor.
