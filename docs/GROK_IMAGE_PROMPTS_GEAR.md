# Grok Image Prompts — Gear Shop Icons

> Use these prompts in Grok (Aurora model) to generate shop icon images.
> Save each as a 512×512 PNG with transparent background.
> Place output files in: `Assets/Resources/ItemIcons/`
> Filename = the `iconPath` value in the JSON (e.g. `ring_iron.png`).

---

## Base Style Block

**Paste this at the START of every prompt below:**

```
Dark fantasy RPG item icon on a fully transparent background. Single item centered, 
slightly angled three-quarter view from above-left, dramatic directional lighting 
from upper left, deep shadows. Highly detailed, painterly-realistic, rich textures. 
No background, no ground plane, no shadow beneath the item. Style: dark fantasy, 
Elarion world — melancholy, ancient, beautiful but worn. 512x512, PNG.
```
