# PRODUCTS — monetization roadmap (Samantha / DeNelle Studios)

> Goal: make the FIRST dollar from skills + tools already built, instead of only spending on dev.
> Honest research backing every call: `docs/MARKET_RESEARCH.md` (URL-cited). This doc is the *decision* layer.
> Core principle established this session: **you do knowledge -> structure (the scarce half); AI does
> structure -> tool (now cheap).** So the bottleneck is never "can we build it" — it's "will anyone pay,"
> which is why we researched marketability BEFORE building.

## The blunt verdict (from the research)
Three of the four tool ideas are **commoditized or free already** — building them would be cheap but they
wouldn't sell. The fourth idea — **packaging YOUR methodology** — is the one with real margin, *because it's
the one thing that can't be cloned for free: your lived experience.* So the strategy flips from "sell tools"
to "sell the structure/judgment only you have."

| Idea | Verdict | Why |
|---|---|---|
| **AI-3D rig normalizer** (Tripo->Mixamo) | **SKIP as conceived** | Tripo/Meshy auto-rig, Unity's free Humanoid auto-map, and free OSS (UniRig) already cover it; much of the "pain" online is Tripo's own SEO. Maybe-only as a niche $10-20 QA/repair utility. |
| **AI-agent guardrails — as a TEMPLATE pack** | **SKIP** | Anthropic docs + GitHub Spec Kit + 1,100+ free templates crush template/PDF pricing. |
| **AI-agent guardrails — as a WAR-STORY cohort/teardown** | **PURSUE FIRST** ✅ | The only tier with real margin (Maven-style cohorts ~$3k). Your moat = the *real* story of running an agent fleet to ship a game, with your PM judgment — not a doc anyone can copy. |
| **Offset Forge (standalone)** | **SKIP** | "Parent to bone + nudge" is the free 5-min answer; a free MIT repo already does the JSON-offset version. It's a feature, not a product. |
| **VFX Parade (paid)** | **SKIP** | Big VFX packs ship free demo/WebGL browsers; the paid-browser category sells so little its products have no star ratings. |

## The play: sell the methodology, not the tools
**Product:** a premium **"How I run an AI agent fleet to actually ship a game"** — vertical, story-driven,
your-judgment-forward. Forms, cheapest first:
1. **One public teardown post + a waitlist** (THIS WEEK, ~free) — a concrete write-up/thread: "I'm a PM, not
   an engineer. Here's the work-order pipeline + canon + gates + instrument-first system I use to keep
   Claude/agents on the rails building a real Unity game — and what broke when I didn't." Link a waitlist /
   email capture. **This IS the validation** — if people want in, the demand is real.
2. **If the waitlist bites -> a cohort / paid teardown series** (the margin tier). Live, story-driven, your
   PM lens applied to AI dev. This is where the money is and where you're un-clonable.
3. Newsletter / ongoing as a long tail.

**Why it fits you:** it's the exact thing you're best at — turning messy reality into *structure* — applied to
the hottest unsolved problem (managing AI coding agents). And you're not theorizing; you have the receipts
(this repo, the canon, the gates, tonight's session).

## Tools: reposition as reputation, not revenue
- **Offset Forge + VFX Parade** -> release **FREE** (Asset Store / GitHub) as credibility seeds that point
  back at the paid methodology product. They prove you build real things; they don't need to earn directly.
- **AI-3D rig utility** -> park. Only revisit as a tiny paid QA/repair utility IF the research's "niche" gap
  turns out real (low priority).
