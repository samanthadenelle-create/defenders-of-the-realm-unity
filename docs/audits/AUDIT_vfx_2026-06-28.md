## 3. URP magenta-shader risk

**Root mechanism (confirmed, not inferred):** nearly every wired Lana Studio prefab references
materials bound to **legacy built-in particle shaders** — `Particles/Additive` (fileID `10720`)
and `Particles/Alpha Blended` (fileID `10721`) under built-in shader guid
`0000000000000000f000000000000000`. 19 of Lana's 22 materials use these; **all 29 wired Lana
prefabs reference them** (e.g. `States/Level_up.prefab` pulls 11 such material refs). Spells Pack
particle materials are likewise built-in (`fileID 210/211` Particles/Standard, 110 of 118 mats).
Under URP these resolve to `Hidden/InternalErrorShader` → opaque magenta billboard quads.

**This is already mitigated at runtime** by `VFXManager.ProofUrpParticleShaders` (WO-602,
`VFXManager.cs:567-654`): on every spawn it walks the instance's `ParticleSystemRenderer`s,
detects any legacy/built-in/error particle shader by name (`IsLegacyParticleShader`, matches the
`"Particles/"` substring + null/error), and swaps in `Universal Render Pipeline/Particles/Unlit`
with the correct additive/alpha blend. The required URP shader **is present in
`AlwaysIncludedShaders`** (guid `0406db5a14f94604a8c57ccfbc9f3b46`), so the proofer will not no-op
in a build. WO-420 had only proofed the *procedural* `AbilityVfxKit`; WO-602 extended it to
catalog prefabs — this is the "spell cast just fixed."

### Remaining magenta risk (real, beyond the spell-cast fix)

1. **`WeatherManager` spawns bypass the proofer.** It calls `Instantiate(...)` directly on
   `_shootingStarPrefab`, `_rainPrefab`, `_rainSplashPrefab` (`WeatherManager.cs:363, 553, 561`)
   — these never pass through `VFXManager.Play`, so `ProofUrpParticleShaders` never runs on them.
   If any of those inspector-assigned prefabs carry legacy built-in particle shaders, they render
   magenta with no fallback. File: `Assets/_Modules/Village/Vfx/WeatherManager.cs`.
   *Recommendation:* route weather spawns through VFXManager, or call the proof helper on the
   instantiated instance.

2. **Proofer is name-based and per-instance, not authoritative.** `IsLegacyParticleShader` keys on
   the shader *name* containing `"Particles/"`. A legacy material whose shader name does not contain
   that token (e.g. a plain `Standard`/`Diffuse`-shaded billboard) would not be re-shaded — it would
   render lit-but-wrong rather than caught. Low risk for the current wired set (all are
   `Particles/*`), but it is a coverage gap if new packs are wired. File:
   `Assets/_Modules/Village/Vfx/VFXManager.cs:658-670`.

3. **Source prefabs are still authored magenta-on-disk.** The packs were never bulk-upgraded
   (`Lana Studio/Casual RPG VFX/Upgrade for URP.unitypackage` is unimported). Any code path that
   instantiates a Lana/Spells prefab *without* going through VFXManager (current or future) inherits
   the risk. The runtime proofer is a safety net, not a source-of-truth fix.

**Not at risk:** Mirza Beig prefabs — 658 of their materials already use URP `Lit`
(guid `933532a4…`); only 5 demo mats use built-in shaders, and none are wired.

## 4. Bottom line

- Catalog covers 45/78 types; biggest free wins are **boss/elite explosions (Spells Pack),
  portal loops (Mirza — currently 0% used), and Pet/Tower aura shields (Lana Shields/ — 0% used)**,
  all wireable with single catalog rows.
- Magenta from catalog VFX is handled at runtime (WO-602 + AlwaysIncludedShaders is correct).
- The **one real remaining magenta hole is `WeatherManager`'s direct `Instantiate` path**, which
  skips the proofer entirely — `Assets/_Modules/Village/Vfx/WeatherManager.cs:363,553,561`.
