> **The §12 read:** the audio subsystem is the *inverse* of tonight's VFX finding. VFX had 20 enum
> members with no row, loudly missing once you looked. Audio has **no unbound enum members** but
> **five unwarned null paths**, so a missing sound produces no trace line at all. An audio system that
> silently plays nothing is the same class of defect as an instrument that lies — and it is harder to
> notice, because the absence of a sound in a noisy scene reads as normal.

# PART 5 — HOW TO BIND A SOUND CORRECTLY

Four mechanisms exist. **Pick by which hook you are filling**, and note that only one of them takes an
owner tag directly.

### Route 1 — an `EnemyTypeVfxSet` list (GAP-A/B/C — tonight's route)
1. **Owner tags** the clip(s) per list per family — the pick is hers, not the CLI's (project canon;
   memory `vfx-map-owner-tags-no-creative-pick`).
2. To change **every** family at once: add the clip references to `_hitSounds` / `_deathSounds` /
   `_attackSounds` in `Assets/Resources/Enemies/EnemyVfxSet_Default.asset` (lines `16`, `18`, `19`).
3. To give **one** family its own character: create
   `Assets/Resources/Enemies/VfxSets/EnemyVfxSet_<family>.asset` (lowercase family name — the resolver
   lowercases at `EnemyTypeVfxLibrary.cs:102`). Rung 1 wins over the default
   (`EnemyTypeVfxLibrary.cs:101-106`).
4. **For attack sounds only**, the clip alone may not be enough: `PlayTypeSound` plays through the
   *enemy's own* `AudioSource` (`Enemy.cs:993`), and `EnsureAudio` deliberately never adds one
   (`Enemy.cs:925-933`). Verify a runtime-built enemy actually has an `AudioSource` child, or the
   attack stays silent with a filled list.
5. Consider also giving the attack beat a fallback (`Enemy.cs:989`, `CombatSfxFallback` at `:977`) so
   it can never regress to silence — that is a code change and belongs in its own WO.

### Route 2 — a named `Resources/Sfx/<Name>` key (GAP 3.3, 3.4)
1. **Owner tags** source clip → loader name.
2. Add the row to the mapping table in `Assets/Editor/Audio/SfxResourceMirror.cs` —
   `CombatMirror` (`:106`) for string-name keys, `LeohpazMirror` (`:186`) for `Sfx_<SfxId>` keys.
3. Run `Defenders > Audio > Mirror SFX to Resources`, or headless
   `.\run-unity-method.ps1 DeNelle.Editor.Audio.SfxResourceMirror.Mirror` (`SfxResourceMirror.cs:56`).
   It copies via `AssetDatabase.CopyAsset` (correct `.meta`/GUID), then normalises the importer so no
   per-platform overrides survive (`:271-283`, keeps WO-682 `SFX_WEBGL_OK` green).
4. **⚠ Commit the copies under `Assets/_Modules/Audio/Resources/Sfx/`.** The Leohpaz source pack is
   gitignored (`.gitignore:372`), so on a fresh clone only the mirrored copies exist. Editing the table
   without running the tool and committing the output **changes nothing that ships**
   (`SfxResourceMirror.cs:50-55` says this explicitly).
5. Add the key to `CombatSfxResourceNames` (`AudioService.cs:718-726`) if it is combat-hot, so the
   WebGL decode lands in the load transition instead of the first swing.

### Route 3 — a `SfxId` (GAP 3.2)
1. **Owner tags** clip → `SfxId`.
2. Mirror it to `Assets/_Modules/Audio/Resources/Sfx/Sfx_<Id>.wav` via Route 2's `LeohpazMirror` table.
   `ProceduralSfx.For` checks that exact path first (`ProceduralSfx.cs:62,68`) and the synth tone is
   dropped automatically. **No code change.**
3. Do **not** reach for `SfxClipLibraryBuilder` (`Assets/Editor/Audio/SfxClipLibraryBuilder.cs`) to do
   this. It bakes *synth placeholder* WAVs and writes a `SfxClipLibrary.asset` that does not currently
   exist; running it would create a library that **wins over** the authored `Sfx_<Id>` drop-ins
   (`AudioService.cs:654` is checked before `:669`) and would replace real audio with tones.

### Route 4 — a `MusicTrack` (GAP 3.6)
1. Place the file under a `Resources/` folder — `Assets/Audio/Resources/` is the convention.
2. Add `TryAssignClip` (primary) or `TryAddClip` (pool extra) in
   `Assets/_Modules/Audio/AudioBootstrap.cs:102-145` with the Resources short name (no extension).
3. **Only `Battle` and `Overworld` are pooled** (`AudioService.cs:501,504`); `AddMusicClip` on any
   other track routes to `SetMusicClip`, which *replaces* rather than appends
   (`AudioBootstrap.cs:108-113`). A "variant" on `Dungeon` or `Defeat` will silently overwrite the
   primary.
4. A miss here does warn (`:190-195`), so a bad key self-reports on the next run.

### After any route — verify, do not assume
- Compile gate: `DeNelle.Editor.CompileGate.Run` → `COMPILE_GATE_OK`.
- Data/regression: the SFX resolve oracle already exists —
  `Assets/Editor/Regression/SfxResolveRegression.cs:30,41`. **Extend it with the newly bound key**, so
  the binding is protected by a test and cannot silently un-bind the way `_typeVfxSet` did.
- Felt-verify: per §13 the **PO closes**. Headless cannot judge whether an orc's swing *sounds right*.
