## Root cause (data-pinpointed)
The seam trigger + the east/north/west gates resolve to a navmesh **island ~7 km from the hero's
castle island** (`closest 7067.1m, path=PathPartial`). The **four-side gate generalization**
(`f82e2b00`, rotation-generalized RuntimeRegionGate → south/west/north/east gates in `region-gates.json`)
added gates on sides where the OuterWorld navmesh is **not reachable / is positioned far off** — only the
**south corridor** (WO-468 Phase 1, `dec10543` — the path actually played) is traversable. So:
- by walking, the hero can only reach 2/5 gates and never trips `RuntimeSeam_Trigger` on the off sides;
- the BattleArena return lands the hero ~7 km from the engagement spot (same island/coordinate mismatch —
  isolated battle scenes sit far from the main world, and the return for the off-side encounter doesn't
  resolve back to the castle island).

Note: the owner plays via the SOUTH gate and the loop works there — these failures are on the **non-south
gates + the dual-island coordinate gap**, exactly the "un-stack regions + real NavMeshLink seam +
dual-navmesh kill" mandate explicitly **deferred to Phase 2** by `dec10543`.
