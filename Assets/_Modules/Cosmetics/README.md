# Cosmetics — `DeNelle.Cosmetics`

Cosmetics + battle pass + Glimmer (cosmetic currency).

## Files

- `CosmeticCatalog`, `CosmeticApplier` — definitions + applying skins
- `BattlePassManager` — battle pass progression (data types in `Core/Data/`)
- `GlimmerCurrencyService` — Glimmer balance (open design question:
  `docs/GLIMMER_ECONOMY_OPEN_QUESTION.md`)

Shop UI lives in `HUD/CosmeticShopPanel` (WO-236).
