# DialogueUI — `DeNelle.DialogueUI`

Intro cinematic + companion dialogue presentation layer.

## Files

- `IntroSequencePlayer` — plays the opening sequence
- `IntroCommandBridge` — command hooks into the sequence
- `CompanionDialoguePresenter` — renders companion dialogue
- `PortraitCache` — portrait sprite caching

Dialogue events flow through `Core/Events/DialogueEventBus`.
